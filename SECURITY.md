# Security policy

Maintainer: Vitalii Babenko. Support is retrospective; reproducibility and security corrections may be reviewed without a response-time commitment or supported deployed service.

Report vulnerabilities privately to [vbabenko2191@gmail.com](mailto:vbabenko2191@gmail.com). The maintainer approved publication of this address. GitHub private vulnerability reporting becomes a second private channel once it is enabled after publication (see the [release checklist](docs/release-checklist.md)). Email always works. Rights holders may request removal of third-party material by the same email; see the [publication decision](docs/data-sources.md#publication-decision).

Do not put credentials, personal data, or secret-bearing exploits in public issues. Include the affected commit, reproduction steps, impact, and a redacted example in your email.

Installation may use the network; analysis and tests should stay offline. Snapshots and imported text are untrusted inputs. The [data-source policy](docs/data-sources.md) documents retained identifiers and unresolved rights.
