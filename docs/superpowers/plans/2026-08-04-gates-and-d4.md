# Frozen Gate Artifacts and D4 Diagnostics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce manifest-bindable machine results for the frozen D2/D3/D3b registrations and make every published D4 diagnostic a seeded computation, while keeping all gates frozen and D4 diagnostic-only.

**Architecture:** The three gate CLIs remain their registered computations; each writes a compact result JSON alongside its existing human report, and a small artifact builder validates and combines those JSON files. `cli_card` consumes only that combined versioned artifact for gate lineage. D4 obtains all comparison values from the same supplied store and rules, emits a JSON result as the single data source for its CSV and Markdown report, and never returns a gate decision.

**Tech Stack:** Python 3.12, stdlib `json`/`csv`/`random`, PyYAML configuration already used by the project, pytest, Ruff, SQLite temporary stores.

---

The provenance/run-manifest plan owns raw snapshot hashes, output hashes, and tracked run-bundle locations. This plan writes deterministic result files to the requested `--out` directory and supplies their schemas to that plan; it does not change registration YAML, category capacities, or gate predicates.

## Stable result schemas

The exact JSON produced by each gate is intentionally small and contains only values already computed by the unchanged registered invocation. All floating values are JSON numbers, not display-rounded strings.

`conditions` has named condition values, thresholds, and booleans. D2 has `margin` and `ci`; D3 has `margin`, `ci`, and `slope`; D3b has the same three fields, with `open_for_test: true` only for `ci`. The artifact builder requires gate names exactly `{"d2", "d3", "d3b"}`, requires an exit code consistent with the verdict, and preserves registrations/configuration as observed inputs rather than deriving new thresholds.

D4 uses explicit, non-ambiguous names:

`rank_correlation` is Spearman correlation of ordinal category positions (category order in `rules.category_capacities`) for the predicted card and derived outcome. The count fields partition the 16 teams by absolute ordinal displacement; the implementation checks that their sum equals `len(card)`.

```python
# src/ti26/gate_artifacts.py
EXPECTED_GATES = frozenset({"d2", "d3", "d3b"})

def _validate_gate_result(result: dict[str, Any], expected_gate: str) -> None:
    if result.get("schema") != "ti26.gate-result.v1" or result.get("gate") != expected_gate:
        raise ValueError(f"invalid {expected_gate} gate result")
    if result.get("verdict") not in {"PASS", "FAIL"}:
        raise ValueError(f"invalid {expected_gate} verdict")
    if (result["verdict"] == "PASS") != (result.get("exit_code") == 0):
        raise ValueError(f"{expected_gate} verdict and exit_code disagree")
    if not isinstance(result.get("conditions"), dict) or not result["conditions"]:
        raise ValueError(f"missing {expected_gate} conditions")

def write_frozen_gate_artifact(paths, destination, *, source_revision):
    if set(paths) != EXPECTED_GATES:
        raise ValueError(f"expected gate results {sorted(EXPECTED_GATES)}")
    gates = {name: json.loads(path.read_text()) for name, path in sorted(paths.items())}
    for name, result in gates.items():
        _validate_gate_result(result, name)
    artifact = {"schema": GATE_ARTIFACT_SCHEMA, "source_revision": source_revision, "gates": gates}
    destination.write_text(json.dumps(artifact, indent=2, sort_keys=True) + "\n")
    return artifact

def load_frozen_gate_artifact(path):
    artifact = json.loads(Path(path).read_text())
    if artifact.get("schema") != GATE_ARTIFACT_SCHEMA:
        raise ValueError("unexpected frozen gate artifact schema")
    for name in EXPECTED_GATES:
        _validate_gate_result(artifact.get("gates", {}).get(name, {}), name)
    return artifact
```

def random_card_control(outcome, capacities, *, samples: int, seed: int) -> dict[str, object]:
    labels = [category for category, count in capacities.items() for _ in range(count)]
    if len(labels) != len(outcome):
        raise ValueError("card capacities must equal outcome size")
    rng, teams, counts = random.Random(seed), sorted(outcome), Counter()
    for _ in range(samples):
        shuffled = labels.copy()
        rng.shuffle(shuffled)
        score = sum(shuffled[index] == outcome[team] for index, team in enumerate(teams))
        counts[score] += 1
    return {"samples": samples, "seed": seed, "mean_score": sum(k * v for k, v in counts.items()) / samples,
            "score_counts": {str(k): counts[k] for k in sorted(counts)}}

def naive_strength_ladder(strengths, capacities, *, stable_ids):
    labels = [category for category, count in capacities.items() for _ in range(count)]
    teams = sorted(strengths, key=lambda team: (-strengths[team], str(stable_ids[team])))
    return dict(zip(teams, labels, strict=True))

def rank_diagnostics(card, observed, category_order):
    position = {category: index for index, category in enumerate(category_order)}
    distances = [abs(position[card[t]] - position[observed[t]]) for t in sorted(card)]
    exact = sum(distance == 0 for distance in distances)
    off_by_one = sum(distance == 1 for distance in distances)
    off_by_two_or_more = sum(distance >= 2 for distance in distances)
    if exact + off_by_one + off_by_two_or_more != len(card):
        raise AssertionError("rank displacement counts do not partition the card")
    predicted = [position[card[team]] for team in sorted(card)]
    actual = [position[observed[team]] for team in sorted(card)]
    return {"rank_correlation": spearman_ordinal(predicted, actual), "exact": exact, "off_by_one": off_by_one,
            "off_by_two_or_more": off_by_two_or_more}
