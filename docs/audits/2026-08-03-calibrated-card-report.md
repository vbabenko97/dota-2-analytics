# Superseded: calibrated-Glicko production card report

This document no longer publishes results in the current tree. Its strengths,
calibration slope and card assignments had no committed producer binding them to
the store they came from.

The card is regenerated by `ti26.cli_card` into `card/` inside the generated run
bundle under `reports/runs/`, with `card/recommended_card.json` carrying the
assignments and `card/card_provenance.md` the run's own measured slope, spreads
and diagnostics. The bundle's manifest hashes both.

Two things in the prior report were wrong rather than merely unbound. It quoted
gate metrics from three hardcoded string literals, which are now read from the
frozen-gate artifact and labelled with that artifact's source revision. And it
inferred from a measured `g(phi)` range that scalar strengths track the model's
own `expected_score` closely; the range is measured, that inference is not, and
the report now reports the first and disclaims the second.

See [the correction register](2026-08-04-correction-register.md). The prior
narrative remains in Git history.
