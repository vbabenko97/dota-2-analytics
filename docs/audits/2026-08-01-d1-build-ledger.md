# Superseded: D1 build ledger

This document no longer publishes results in the current tree. It was a
build-process record from before this project had ingestion, so the quantities it
reported came from a synthetic strength ladder and from suite counts of the day.

Nothing regenerates them. D1's runs predate the pinned snapshot and are not
reproducible from anything committed, so they are withdrawn rather than restated
or estimated.

The rules engine and card generator it describes are covered by the current test
suite, and the card the project actually ships is generated into the run bundle
under `reports/runs/`.

See [the correction register](2026-08-04-correction-register.md). The prior
narrative remains in Git history.
